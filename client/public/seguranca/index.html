📖 Referência de Comandos

clear / cls - Limpar a tela do terminal
help - Listar comandos disponíveis
ping <ip> - Verificar disponibilidade do host
nmap -sV <ip> - Inventariar serviços e versões
nmap --script vuln <ip> - Localizar vulnerabilidades
ufw default deny incoming - Bloquear tráfego de entrada
ufw allow <serviço> - Liberar um serviço
ufw deny from <ip> - Bloquear um endereço IP
ufw enable / ufw status - Ativar / ver regras do firewall
systemctl stop <serv> - Parar um serviço
systemctl disable <serv> - Desabilitar na inicialização
tail -30 /var/log/auth.log - Ver logs de autenticação
grep "Failed password" /var/log/auth.log - Buscar tentativas no log
sshd_config <chave> <valor> - Ajustar configuração do SSH
service ssh reload - Recarregar o serviço SSH
